# Logic Error Codes

A [logic error](/docs/api/errors#logic-errors) carries a numeric `code` and a human-readable `message`. This table lists every code ConCat defines, with its name and its English (en-US) message. It is generated from ConCat's source.

- Words in braces, such as `{scopes}`, are filled in from the error's `args` when ConCat builds the message.
- The `message` an API response carries is ConCat's English text. For a few codes it's worded slightly differently from this table.
- Most codes come from the Housekeeping and attendee apps, not from the API. The codes the API endpoints and the OAuth flow can return include:

| Code | Name | Returned by |
| ---: | --- | --- |
| 10 | `UserAlreadyHasRole` | [Grant a role to a user](/docs/api/endpoints/v0/reference/grant-user-role) |
| 31 | `OAuthInvalidScope` | [Token requests](/docs/api/gettingstarted/oauth) and the authorization request |
| 32 | `OAuthInvalidRedirectURI` | [Token requests](/docs/api/gettingstarted/oauth) and the authorization request |
| 49 | `OrderNotPaid` | [Revoke an order item](/docs/api/endpoints/v0/reference/revoke-order-item) |
| 79 | `OrderIsPaid` | [Remove an order item](/docs/api/endpoints/v0/reference/remove-order-item) |
| 112 | `BadPaginationToken` | Every search and paginated list endpoint |
| 114 | `CannotRemoveAddonFromCart` | [Remove an order item](/docs/api/endpoints/v0/reference/remove-order-item) |
| 116 | `ApplicationNotGranted` | [Service token requests](/docs/api/gettingstarted/oauth#service-integration) |
